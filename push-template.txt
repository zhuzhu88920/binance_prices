# Bark 推送排版模板
# 修改此文件即可改变推送格式，无需改代码
#
# 可用占位符 = CSV 里的列名（用花括号包起来）:
#   {合约} {方向} {杠杆} {已投保证金} {总收益} {收益率}
#   {已配对利润} {未配对盈亏} {配对次数} {运行时间} {风险率}
# 特殊变量：
#   {序号}        → 机器人编号 (1,2,3...)
#   {时间}        → 当前时间
#   {总收益汇总}  → 所有机器人收益加总
#   {正负符号}    → 🟢 或 🔴
#
# 语法：
#   title:xxx     → 通知标题（Bark的大字体那行，只取第一行）
#   {每个机器人}...{结束}  → 中间内容对每个机器人重复一次
#   # 开头的行为注释，不会推送

title:🤖 {当前币价} | {正负符号}{总收益汇总} | {时间}
{每个机器人}
[{序号}]💰{已投保证金} |🔁{配对次数}对
{总收益}({收益率})|{已配对利润}({配对收益率})|{未配对盈亏}({未配对率})
{方向}{杠杆} | {风险率} |⏱{运行时间}
 
{结束}
