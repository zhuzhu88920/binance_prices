# Binance 网格机器人数据抓取

自动抓取 Binance U本位合约网格交易页面的机器人数据，输出 CSV + 手机推送。

## 功能

- 定时切换 tab 刷新数据 → 读取 DOM 表格 → 输出结构化数据
- 每次覆盖写入 `output/grid_bots.csv`（固定文件名，不产生历史垃圾）
- 同时生成手机友好文本 `output/grid_bots.txt`
- 抓取当前页面标记价格（币价），注入每行数据
- 通过 **Bark App** 推送到 iPhone（可选）
- 通过 `columns.conf` 和 `push-template.txt` 自定义输出格式，无需改代码

## 前置要求

1. **Edge 浏览器以调试端口启动**：

   ```powershell
   msedge --remote-debugging-port=9222
   ```

   在打开的 Edge 中登录 Binance 并进入网格交易页面（U本位合约）。

2. **安装依赖**：

   ```bash
   npm install
   ```

## 快速开始

### 方式一：一键启动（推荐）

双击 `start.bat`，自动完成：

1. 检测 Edge 调试端口（9222），未运行则自动启动
2. 杀掉残留的旧 `auto-scrape.js` 进程
3. 启动抓取脚本

> 重启电脑后**只需这一步**。

```bash
start.bat
```

也支持传参：

```bash
start.bat --interval 10 --bark YOUR_KEY
```

### 方式二：手动启动

```bash
# 1. 先启动 Edge（带调试端口）
msedge --remote-debugging-port=9222

# 2. 再开终端跑脚本
node.exe auto-scrape.js
```

### 命令行参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--interval N` | 抓取间隔（分钟） | 5 |
| `--bark <key>` | Bark 推送 key | 从 `.env` 读取 |

示例：

```bash
# 每10分钟抓一次
node.exe auto-scrape.js --interval 10

# 指定 Bark key
node.exe auto-scrape.js --bark YOUR_BARK_KEY
```

## 工作流程

```
┌─────────────────────────────────────────────────┐
│  启动 auto-scrape.js                             │
│  ↓                                               │
│  连接 Edge CDP (localhost:9222)                  │
│  ↓                                               │
│  切到「仓位」tab → 等 800ms                      │
│  ↓                                               │
│  切回「机器人」tab → 等 1500ms                   │
│  ↓                                               │
│  从 DOM [role="table"] 提取表格数据               │
│  ↓                                               │
│  等 1s → 再提一次 → 对比机器人数量                │
│  ├─ 一致 → 用第二次数据（更新鲜）                 │
│  └─ 不一致 → 等 2s → 第三次提取                   │
│  ↓                                               │
│  提取标记价格（币价）                              │
│  ↓                                               │
│  写入 grid_bots.csv (覆盖)                        │
│  写入 grid_bots.txt (覆盖)                        │
│  终端预览                                         │
│  ↓                                               │
│  Bark 推送到 iPhone（如已配置 key）                │
│  ↓                                               │
│  等待 N 分钟 → 重新开始                           │
└─────────────────────────────────────────────────┘
```

### 为什么用 tab 切换而不是刷新页面？

| | 整页 reload | tab 切换刷新 |
|---|---|---|
| 刷新范围 | 整个页面（JS/CSS/WebSocket 全重来） | 只刷新表格区域的 API 数据 |
| 耗时 | 4-5秒 + 渲染等待 | ~2.3秒（两次 tab 切换 + 渲染） |
| 副作用 | WebSocket 重连、可能弹提示框、页面跳回默认状态 | 只影响表格，页面其他状态保持 |
| 长期运行 | 重，内存泄漏风险 | 轻，SPA 内部状态切换 |

## 配置文件说明

### `columns.conf` — 列过滤

控制 CSV 输出中包含哪些字段。格式为 `列名 = y/n`，`y` 为启用、`n` 为禁用。

修改后保存即可生效，无需重启脚本。

```conf
# 格式：列名 = y(保留) | n(跳过)

抓取时间=n
当前币价=y          ← 启用：每行都带当前币价
合约=y
方向=y
杠杆=y
日期=y
时间=n              ← 禁用：不输出到CSV
已投保证金=y
总收益=y
收益率=y
...
```

#### 全部可用字段（28个）

| 字段 | 说明 |
|------|------|
| 抓取时间 | 数据抓取的时间戳 |
| **当前币价** | 页面标记价格（如 `2,305.66`） |
| 合约 | 如 `ETHUSDC` |
| 方向 | 中性 / 做多 / 做空 |
| 杠杆 | 如 `20x`、`10x 移动` |
| 日期 | 创建日期 `2024-01-15` |
| 时间 | 创建时间 `08:30:00` |
| 已投保证金 | 如 `1,500.00 USDC` |
| 保证金类型 | 逐仓 / 全仓 |
| 总收益 | 如 `+48.00 USDC` |
| 收益率 | 如 `+3.20%` |
| 资金费用 | 资金费用金额 |
| 费率 | 资金费用率 |
| 已配对利润 | 已完成配对的累计利润 |
| 配对收益率 | 已配对利润的收益率 |
| 未配对盈亏 | 尚未配对部分的浮动盈亏 |
| 未配对率 | 未配对盈亏的收益率 |
| 配对次数 | 已完成的配对次数 |
| 价格区间下限 | 网格价格区间低点 |
| 价格区间上限 | 网格价格区间高点 |
| 网格数量 | 网格总数 |
| 每笔数量 | 每网格的交易数量 |
| 止盈价 | 止盈价格 |
| 止损价 | 止损价格 |
| 运行时间 | 如 `1天 9分` |
| 强平价格 | 强平价格 |
| 网格状态 | 运行中 / 已停止 |
| 风险率 | 如 `1.23 (低)` |

> **重要**：字段必须在 `ALL_HEADERS` 数组（`auto-scrape.js` 内）中存在才能被识别。新增字段时需同步修改两处。

### `push-template.txt` — 推送排版模板

控制 Bark 手机通知的标题和正文格式。编辑此文件即可自定义推送样式，**无需改代码**。

```text
# 注释行：# 开头的内容不会被推送

title:🤖 {当前币价} | {正负符号}{总收益汇总} | {时间}

{每个机器人}
[{序号}] {已投保证金} {方向}{杠杆}
 💰{总收益} ({收益率})
    {已配对利润}({配对收益率})
    {未配对盈亏}({未配对率})
 🔁{配对次数}对 | {风险率} |⏱{运行时间}
 
{结束}
```

#### 模板语法

| 语法 | 说明 |
|------|------|
| `title:` | 通知标题行（Bark 的大字体行），只认第一个 |
| `{每个机器人}` ... `{结束}` | 循环块：中间内容对每个机器人重复渲染 |
| `#` 开头 | 注释行，不输出 |

#### 可用占位符

| 占位符 | 类型 | 示例 |
|--------|------|------|
| `{时间}` | 特殊变量 | `14:08` |
| `{总收益汇总}` | 特殊变量 | `-502.97` |
| `{正负符号}` | 特殊变量 | 🟢 / 🔴 |
| `{当前币价}` | 特殊变量 | `2,307.95` |
| `{机器人数量}` | 特殊变量 | `3` |
| `{序号}` | 循环内变量 | `1`, `2`, `3`... |
| `{合约}` | CSV列名 | `ETHUSDC` |
| `{方向}` | CSV列名 | `中性` |
| `{总收益}` | CSV列名 | `+60.96 USDC` |
| ... | 其余字段均可使用 | |

### `.env` — 环境变量（可选）

用于存放敏感配置，避免命令行暴露：

```env
# Bark 推送 key（也可通过 --bark 参数传入）
```

## 输出文件

### `output/grid_bots.csv`

带 BOM 的 UTF-8 CSV，Excel 直接打开不乱码。每次覆盖写入，只包含 `columns.conf` 中启用的列。

示例内容：

```csv
当前币价,合约,方向,杠杆,日期,已投保证金,总收益,收益率,...
2,307.95,ETHUSDC,中性,20x 移动,2025-01-13,1,500.00,+60.96,+4.06%,...
```

### `output/grid_bots.txt`

按 `push-template.txt` 渲染后的纯文本，供 Bark 推送使用。

## 常见问题

### Q: 提示 `connect ECONNREFUSED localhost:9222`
Edge 没有以调试端口启动。先执行：
```powershell
msedge --remote-debugging-port=9222
```

### Q: 推送里 `{当前币价}` 没有被替换
1. 确认已重启脚本（Ctrl+C 后重新 `node.exe auto-scrape.js`）
2. 检查日志是否显示 `💰 币价: 2,xxx.xx`
3. 确认 `columns.conf` 中 `当前币价=y` 且该字段在 `ALL_HEADERS` 数组中

### Q: 数据跳动异常
脚本已采用 tab 切换刷新 + 数据校验机制。如仍有异常可尝试：
- 增大间隔时间 `--interval 10`
- 检查网络延迟是否过高

### Q: 如何停止脚本
在终端按 **Ctrl+C**，会显示共执行次数后优雅退出。
